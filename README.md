# 深空编队离线机动指令会签核验台（RFC 9591 FROST / Ed25519 / SHA-512）

离线会签场景下，审查员在机动指令签发前，借助本核验台确认聚合器**未将不同
参与者、承诺或消息拼接**成表面有效的签名。全部代码仅依赖 Python 3.11 标准库。

## 它验证什么

页面（或 API）提交以下字段：稳定审计标识、原始消息、群公钥、阈值、至多
**8 名**参与者的标识 / 公钥份额 / 双随机承诺 D、E / 签名份额，以及聚合签名
（承诺 R 与响应 z）。系统按 RFC 9591 执行：

1. **结构与编码门禁**：标量必须规范（`0 <= s < l`），点必须 32 字节、在
   Ed25519 曲线上且属于素数阶子群（拒绝单位元/小阶点、非规范编码）；标识
   唯一且非零；参与者数必须**恰好等于阈值**且不超过 8。
2. **绑定因子与挑战**：由原始消息、群公钥与**完整承诺集**（列表编码 + 域
   分隔，SHA-512）计算每个 ρ_i，再得群承诺
   `R = ∏ D_i · E_i^ρ_i` 与挑战 `c = H2(m,[R,PK])`。
3. **先逐份验证**：对每个参与者按标识升序的稳定顺序核对
   `G^s_i = D_i · E_i^ρ_i · PK_i^(c·λ_i)`，输出 λ_i、ρ_i、方程左右点与
   **残差摘要**，并定位**首个失败份额**。
4. **再核对聚合签名**：`z = Σ s_i` 且 `G^z = R · PK^c`，输出聚合残差。

非规范标量、不可解码点、重复标识、阈值不符、份额失败、承诺/响应拼接一律
拒绝。

## 审计标识与证据冻结

- 相同 `audit_id` 重传**完全相同**的会签包（规范 JSON 的 SHA-256 相同）→
  直接返回**既有冻结结论**（`reused_existing_conclusion=true`，不重算）。
- 相同 `audit_id` 下消息、承诺或任何字段变化 → **HTTP 409 冲突**，逐字段
  给出变化位置，原始证据（包、结论、时间戳）原样保留，冲突仅追加登记，
  **绝不覆盖**。证据以原子写持久化到 `EVIDENCE_DB`。

## 运行（Compose，宿主端口可配置）

```bash
docker compose up --build            # 默认宿主端口 8080
DESK_HOST_PORT=9090 docker compose up --build
```

或直接运行（无第三方依赖）：

```bash
HOST=0.0.0.0 PORT=8080 EVIDENCE_DB=./data/evidence.json python3 -m app.server
```

- 页面：`http://localhost:8080/`（可“载入真实样例会签包”）
- 健康：`GET /healthz` → `{"status":"ok",...}`

## 一次性验收服务 verify

```bash
./verify
```

`verify` 执行后即退出，以退出码报告：

1. **密码规则代码测试**（`python -m unittest discover -s tests`，24 项）；
2. **业务验收**：真实接口 API/HTTP 冒烟——有效会签接受、篡改份额拒绝并
   精确定位失败份额与残差、冻结/重放/409 冲突语义、页面与静态资源、证据
   接口；
3. **构建检查**：Dockerfile/compose 静态校验；有 Docker 时真实
   `docker build` 并在临时宿主端口启动容器做 `/healthz` 探测；无 Docker
   守护时按镜像 COPY 清单在隔离目录做等价启动冒烟（结果标注 EMULATED）。

全部通过退出码 `0`，任一必检项失败退出码 `1`。

## 目录

```
app/frost.py       RFC 9591 原语：Ed25519 点运算、H1–H5、列表编码、份额/聚合方程
app/verifier.py    结构门禁 + 逐份额验证 + 聚合核对 + 残差摘要
app/store.py       审计标识校验、内容指纹、冻结/冲突证据库（原子持久化）
app/server.py      标准库 HTTP 服务：/healthz、/api/v1、核验台页面
app/web/           页面（真实接口，无桩数据）
tests/             密码规则单测与端到端冒烟
verify             一次性可执行验收服务
Dockerfile         python:3.11-slim，非 root，内置 HEALTHCHECK
```
